# 🛒 E-Commerce Platform

A modern **multi-vendor e-commerce platform** built to provide a complete online shopping experience with buyer, seller, and admin management systems.

The platform allows customers to discover products, manage shopping carts, place orders, and track purchases. Sellers can manage their products and sales, while admins have complete control over the marketplace.

# ⚡ Installation

## Clone Repository

```bash
git clone https://github.com/username/anon-ecommerce.git
```

## Frontend Setup

```bash
cd frontend

npm install

npm run dev
```

## Backend Setup

```bash
cd backend

composer install

php artisan migrate

php artisan serve
```
